Rust · SDK

AETHER-Q — kross-platforma kripto-SDK

Gibrid post-kvant KEM protokolining reference implementatsiyasi: X25519 + ML-KEM-768 (X-Wing), Triple-Hybrid HQC-192 profili, ML-DSA-65/Ed25519 imzolar, Double Ratchet va ChaCha20-Poly1305 / AES-256-GCM record layer. Uch crate: primitivlar, protokol yadrosi, FFI.

UniFFI orqali Python, Kotlin va Swift binding'lari avtomatik generatsiya qilinadi. 30+ test (unit, KAT, interop), clippy -D warnings toza.

Android · E2E

Aether Messenger — post-kvant chat

Kontakt QR orqali almashinadi (markaziy katalog yo'q), kalitlar Android Keystore'da, tarix Room + SQLCipher'da. Rust kutubxonasi NDK bilan arm64/x86_64 uchun yig'iladi.
