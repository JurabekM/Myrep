# Sector Verify — руководство пользователя

Sector Verify проверяет **обычным телефоном**, что секторы базовой станции излучают в соответствии с RF-планом:
находит перепутанные секторы, отсутствующие PCI и поворот антенны, пока бригада ещё на сайте. Приложение работает
полностью офлайн — данные не покидают телефон.

**Требования:** Android 10 или новее (включая Android 16), GPS, сеть LTE или 5G (NR), SIM оператора из плана.
Рекомендуемые телефоны — `docs/DEVICES.md`.

## 1. Подготовка (один раз)
1. Установите приложение (APK или Google Play).
2. **Отключите экономию батареи для приложения**, иначе некоторые телефоны останавливают сбор при выключенном экране:
   - Samsung: Настройки → Приложения → Sector Verify → Батарея → **Без ограничений**;
   - Xiaomi / Redmi / POCO: о приложении → Контроль активности → **Нет ограничений**, включите **Автозапуск**;
   - Tecno / Infinix / Realme: приложение → Батарея → **Разрешить работу в фоне**.
3. **Настройки** (шестерёнка справа вверху):
   - **Имя инженера** — попадает в отчёт.
   - **Пресет анализа:** *Город* (плотная застройка, до 600 м), *Пригород* (по умолчанию), *Сельская местность*.
   - **URL трафика** (необязательно, только `https://`): каждые 2 с отправляется HEAD-запрос, чтобы телефон оставался
     в подключённом режиме и приходил TA. Если поле пустое, предпроверка предупредит.
   - **Проверка устройства (60 с)** — что телефон реально отдаёт (частота, RSRP соседей, TA). Один раз на телефон,
     на открытом месте. Нужны разрешения на местоположение и состояние телефона (выдаются на первой предпроверке),
     иначе — «SIM не найдена или нет разрешения».
   - **Язык приложения** и **язык отчёта** (узбекский, русский, английский) выбираются отдельно.
   - **Тема:** тёмная (по умолчанию), светлая, **солнце** (высокий контраст при ярком солнце).

## 2. Импорт RF-плана
**Сайты → Импорт плана CSV**. Формат (UTF-8, заголовок обязателен, разделитель `,` или `;`):
```
site_code,site_name,lat,lon,mcc_mnc,sector,rat,band,arfcn,pci,azimuth_deg,hpbw_deg,mech_tilt_deg,elec_tilt_deg,height_m
NAV-0123,Navoiy Markaz,40.1032,65.3685,43405,S1,LTE,B3,1300,141,0,65,2,4,30
```
Ошибки показываются с номером строки; пока файл не будет полностью корректным, ничего не сохраняется.
При повторном импорте сайта его секторы обновляются. Каждое измерение хранит **план на момент измерения**:
повторный импорт не меняет прежние результаты, отчёты и ZIP — новый план влияет только на следующие измерения.

## 3. Измерение на сайте
1. **Сайты** → выберите сайт → **Предварительная проверка**.
2. Все строки должны быть зелёными или жёлтыми. При **красной** (блокирующей) кнопка «Начать» недоступна:
   разрешения, SIM с MCC/MNC из плана, включённый GPS.
   С **жёлтыми** (предупреждения) начать можно, но качество результата может снизиться: уведомления выключены,
   режим 2G/3G, *точность GPS* хуже порога (по умолчанию ≤ 15 м — выйдите на открытое место), не пройдена проверка
   устройства, плановые PCI ещё не видны, пустой URL трафика.
3. **Начать** → обойдите сайт пешком по кругу радиусом **150–400 м**, по возможности **полным кольцом**
   (около 15–20 минут). Сбор продолжается и при выключенном экране.
4. Экран **живого измерения**: карта (цвет трека = обслуживающий PCI), **радар покрытия** (36 направлений по 10°),
   карточки PCI (RSRP, оценка и плановый азимут, цвет статуса).
5. Уведомление **«Результат готов»** — покрытия достаточно. Нажмите **Завершить**.

## 4. Результат
- **Полярная диаграмма** по каждому ARFCN: план — пунктир, измерение — линия с дугой 95% доверия.
- **Вердикты:** PASS, WARN (отклонение 20–45° или большая неопределённость), FAIL (ошибка: перепутаны секторы,
  нет PCI, > 45°), INCONCLUSIVE (недостаточно покрытия или оценка ненадёжна).
- **Находки и рекомендации** — что проверить (конфигурация/CPRI, порты диапазона, азимут антенны…).
- **Повторная проверка** — новое измерение после исправления.

## 5. Отчёт
**Отчёт (PDF, ZIP)** → **Сформировать отчёт**: PDF на выбранном языке, `report.json`, **подписанный** ключом
Android Keystore (EC P-256), и ZIP с полной сессией. В офисе: `sv-replay verify сессия.zip` и `sv-replay analyze`.

## 6. Проблемы
| Признак | Причина и решение |
|---|---|
| «Нет SIM с MCC/MNC» | Оператор SIM не совпадает с планом |
| Частота < 0.5 Гц | Телефон редко обновляет CellInfo — используйте рекомендованные модели (`docs/DEVICES.md`) |
| Все секторы INCONCLUSIVE | Кольцо неполное — пройдите пустые направления радара |
| Приложение закрылось или упало | Откройте снова. Окно «Незавершённое измерение»: если измерение прервано — **Продолжить** (данные сохранены) или **Прервать**; если ещё идёт — **Открыть измерение** |
| «Нет разрешения на местоположение» (при продолжении) | Откройте сайт и пройдите предпроверку — после выдачи разрешения можно продолжить |
| При выключенном экране замеры не растут | Включена экономия батареи — раздел 1, пункт 2 |
| Плохая точность GPS (жёлтый) | В здании или закрытое небо — выйдите на открытое место и подождите 1–2 минуты |
| Сообщить об ошибке | Настройки → **Экспорт журналов сбоев** (без координат) |
