# Политика конфиденциальности — Sector Verify

**Коротко: приложение не собирает и никому не передаёт данные.**

- **Местоположение (GPS) и измерения сотовой сети** (RSRP, PCI, ARFCN, TA) собираются только во время запущенного вами
  измерения и хранятся **только на телефоне** в зашифрованной базе (SQLCipher). Фоновое местоположение не используется.
- **Данные SIM** (MCC/MNC) читаются только для выбора SIM, соответствующей плану; IMSI, номер телефона, IMEI не читаются.
- **Сеть:** приложение отправляет только пустой `HEAD`-запрос на необязательный HTTPS-адрес из настроек (чтобы телефон оставался
  в подключённом режиме). В запросе нет личных данных и результатов измерений.
- **Телеметрии, аналитики, рекламы, Firebase, Google Play Services — нет.**
- **Резервное копирование:** данные не переносятся в облако и на другие устройства.
- **Передача:** PDF-отчёт и ZIP сессии отправляете только вы сами кнопкой «Поделиться».
- **Журнал сбоев:** при сбое на телефоне сохраняется только стек ошибки; экспортируете его только вы.
- **Удаление:** при удалении приложения или очистке его данных удаляется всё.
