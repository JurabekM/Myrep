# ADR-0011: Ichki API uchun mTLS — sertifikat API kalitiga bog'langan

* Holat: qabul qilingan (2026-10-24, 1-faza P1.3)

## Kontekst

0-fazada operator va terminal endpointlari faqat Bearer API kaliti bilan himoyalangan edi: kalit
o'g'irlansa (log, konfiguratsiya, terminal qurilmasi), istalgan joydan ishlatiladi. Hamyonlar esa
PQ Link (Android Key Attestation + gibrid handshake) bilan ulanadi va mijoz sertifikatiga muhtoj emas.

## Qaror

1. `[http] client_ca` berilsa, TLS server mijoz sertifikatini **so'raydi, lekin majburlamaydi**
   (`WebPkiClientVerifier::allow_unauthenticated`) — hamyonlar sertifikatsiz ulanadi.
2. rustls tekshirgan sertifikatning subject CN'i so'rov kengaytmasiga qo'yiladi (`PeerCert`).
3. `[auth] require_mtls = true` bo'lsa, operator va terminal endpointlari `CN == API kaliti id`
   ni talab qiladi; aks holda `403 MTLS_REQUIRED`. Avval Bearer tekshiriladi (401), keyin mTLS (403).
4. Sandbox: `mpay-server init --tls` mijoz CA'sini (`mtls-client-ca.pem`, kaliti saqlanmaydi) va
   `operator-1`, `terminal-1` sertifikatlarini (EKU clientAuth) yaratadi, `require_mtls = true`.
   `mpay-tsim` sandbox katalogidagi sertifikatni avtomatik ko'rsatadi.
5. Konfiguratsiya tekshiruvi: `require_mtls` TLS va `client_ca` siz ishga tushmaydi.

## Oqibatlar

* O'g'irlangan Bearer kalit yolg'iz yetarli emas — mos shaxsiy kalit ham kerak; begona CA
  sertifikati TLS handshake'da rad etiladi (`tests/e2e/tests/p1_mtls.rs`).
* Sertifikatni bekor qilish (CRL/OCSP) hali yo'q — `TODO(spec):` bank PKI'si bilan (2-faza);
  hozircha bekor qilish = API kalitini almashtirish yoki CA'ni yangilash.
* Android `terminal-app` mTLS'ni P1.4 da oladi (hozir faqat HTTP sandbox).

## Ko'rib chiqilgan muqobillar

* **Majburiy mijoz sertifikati (TLS darajasida)** — hamyonlar uchun ham sertifikat kerak bo'lardi;
  qurilma identifikatori allaqachon attestatsiya bilan tasdiqlanadi.
* **Bearer'siz faqat mTLS** — kalit va sertifikat ikki mustaqil omil; rol va audit aktori kalitdan keladi.
* **Alohida port (ichki API)** — deployment murakkabligi; 2-fazada ingress bilan qayta ko'rilishi mumkin.
