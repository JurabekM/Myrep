# Kelishuv shablonlari

Har shablon — bandlar tartibi va metama'lumot; band matnlari `shared/i18n` dagi `pdf.tpl.*` kalitlarida
(uz va ru; uz-Cyrl avtomatik). `reviewStatus`:

- `PENDING` — yurist (va kerak bo'lsa ulamo) ko'rigidan o'tmagan: ilovada ogohlantirish, PDF'da
  «Tekshiruvdan o'tmagan namuna» belgisi (`BARAKA_OILASI.md` 9).
- `APPROVED` — ko'rikdan o'tgan; o'zgartirilsa `version` oshiriladi va holat qayta `PENDING`.

Shablon matni o'zgarsa — `version` oshiriladi; imzolangan kelishuvlar o'z versiyasini saqlaydi.
